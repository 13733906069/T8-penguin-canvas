================================================================================
  一、国漫模型列表（分页）
================================================================================

接口: GET /api/guoman-models

curl 示例:
  curl -X GET "http://127.0.0.1:18766/api/guoman-models?page=1&size=30&search=小舞"

--------------------------------------------------------------------------------
请求参数 (Query String)
--------------------------------------------------------------------------------

参数    类型    必填    默认值    说明
page    number  否      1        页码，从 1 开始
size    number  否      30       每页数量，范围 1~60
search  string  否      ""       搜索关键词（按 resourceName 模糊匹配），不传或传空返回全部

--------------------------------------------------------------------------------
成功响应示例
--------------------------------------------------------------------------------

{
  "success": true,
  "data": {
    "records": [
      {
        "id": "1886690989611085826",
        "resourceName": "AI清风-小舞-斗罗大陆_v1.0",
        "resourceType": "LORA",
        "thumbnailUrl": "https://xxxx.runninghub.cn/xxx/thumb.png",
        "posterUrl": "https://xxxx.runninghub.cn/xxx/poster.png",
        "version": "v1.0",
        "imageSize": "512x768",
        "createTime": "2024-06-15 10:30:00",
        "owner": { "name": "清风" },
        "desc": "粉色长发, 兔耳发饰, 粉色长裙",
        "versions": [
          {
            "id": "1886690989611085827",
            "version": "v1.0",
            "versionResourceName": "xiaowu_douluo_v1.safetensors",
            "resourceStorageName": "loras/xiaowu_douluo_v1.safetensors",
            "baseModel": "SDXL",
            "triggerWords": "xiaowu, pink hair",
            "desc": "小舞角色模型，适用于斗罗大陆风格"
          }
        ]
      }
    ],
    "total": 156,
    "page": 1,
    "size": 30,
    "totalPages": 6
  }
}

--------------------------------------------------------------------------------
data 层字段说明
--------------------------------------------------------------------------------

字段        类型    说明
records     array   当前页的模型列表
total       number  符合条件的总记录数
page        number  当前页码
size        number  每页数量
totalPages  number  总页数 = ceil(total / size)

--------------------------------------------------------------------------------
records[] 每条记录的顶层字段说明
--------------------------------------------------------------------------------

字段          类型          说明
id            string        模型唯一 ID（RunningHub 资源 ID）
resourceName  string        模型显示名称，如 "AI清风-小舞-斗罗大陆_v1.0"
resourceType  string        资源类型，固定为 "LORA"
thumbnailUrl  string        缩略图 URL（可直接浏览器打开）
posterUrl     string        海报大图 URL
version       string        当前版本号，如 "v1.0"
imageSize     string        推荐出图尺寸，如 "512x768"
createTime    string        创建时间
owner         object|null   模型作者，含 name 字段
desc          string|null   ★ 顶层角色外观描述（纯文本）。
                            空字符串或 "1.0" 表示未填写具体外观。
                            这是传给下游 AI 节点的核心字段
versions      array         模型的所有版本列表

--------------------------------------------------------------------------------
versions[] 每个版本的字段说明
--------------------------------------------------------------------------------

字段                  类型          说明
id                    string        版本唯一 ID
version               string        版本号，如 "v1.0", "v2.0"
versionResourceName   string        ★ 版本对应的文件名，如 "xiaowu_v1.safetensors"。
                                     这是传给 RH submit 接口 lora_name 字段的值
resourceStorageName   string        服务器上的存储路径
baseModel             string        底模名称，如 "SDXL", "Flux"
triggerWords          string|null   触发词，逗号分隔
desc                  string|null   该版本的描述

--------------------------------------------------------------------------------
失败响应
--------------------------------------------------------------------------------

{
  "success": false,
  "error": "RunningHub API 返回 HTTP 502"
}


================================================================================
  二、国漫模型全量拉取（不分页）
================================================================================

接口: GET /api/guoman-models/all

用途: 一次性返回所有模型，供随机抽取等场景使用。
限制: 硬上限 1000 条，超过时 truncated=true

curl 示例:
  curl -X GET "http://127.0.0.1:18766/api/guoman-models/all"

--------------------------------------------------------------------------------
请求参数
--------------------------------------------------------------------------------

无。

--------------------------------------------------------------------------------
成功响应示例
--------------------------------------------------------------------------------

{
  "success": true,
  "data": {
    "records": [ /* GuomanModel 数组，结构同上 */ ],
    "total": 156,
    "cap": 1000,
    "truncated": false
  }
}

--------------------------------------------------------------------------------
额外字段说明
--------------------------------------------------------------------------------

字段        类型     说明
total       number   实际总记录数
cap         number   硬上限 = 1000
truncated   boolean  是否被截断。true 表示模型数超过 1000，实际返回只有前 1000 个。
                    调用方应在 UI 中提醒用户「模型库超过 1000 个，仅在前 1000 个中随机」


================================================================================
  三、按 ID 批量查询模型
================================================================================

接口: POST /api/guoman-models/by-ids

用途: 根据收藏的模型 ID 列表，批量查回完整模型信息。

curl 示例:
  curl -X POST http://127.0.0.1:18766/api/guoman-models/by-ids \
    -H "Content-Type: application/json" \
    -d '{"ids": ["1886690989611085826", "1886690989611085888"]}'

--------------------------------------------------------------------------------
请求参数 (JSON Body)
--------------------------------------------------------------------------------

字段  类型      必填  说明
ids   string[]  是    模型 ID 数组。空数组返回空列表。不存在的 ID 静默跳过

--------------------------------------------------------------------------------
成功响应示例
--------------------------------------------------------------------------------

{
  "success": true,
  "data": {
    "records": [ /* GuomanModel 数组，只包含匹配到的 */ ]
  }
}

--------------------------------------------------------------------------------
注意事项
--------------------------------------------------------------------------------

当前实现采用"拉全量 + 内存过滤"方式，并非按 ID 逐条查询。
如果模型总量大幅增长，建议联系我们对这个接口做优化。


================================================================================
  四、RunningHub 任务提交（AI 生成）
================================================================================

接口: POST /api/proxy/runninghub/submit

用途: 使用选中的模型，提交 AI 图片生成任务。
鉴权: 后端使用画布设置中配置的 RunningHub API Key，调用方无需传 Key。

curl 示例:
  curl -X POST http://127.0.0.1:18766/api/proxy/runninghub/submit \
    -H "Content-Type: application/json" \
    -d '{
      "webappId": "2066139220363800578",
      "instanceType": "plus",
      "nodeInfoList": [
        { "nodeId": "1569", "fieldName": "lora_name", "fieldValue": "xiaowu_douluo_v1.safetensors" },
        { "nodeId": "1643", "fieldName": "text", "fieldValue": "粉色长发, 兔耳发饰, 粉色长裙, 纤细身材" },
        { "nodeId": "1644", "fieldName": "value", "fieldValue": false },
        { "nodeId": "1646", "fieldName": "text", "fieldValue": "站立姿态, 微笑, 双手自然垂放" },
        { "nodeId": "1496", "fieldName": "text", "fieldValue": "樱花树下, 阳光透过花瓣, 柔和光线" },
        { "nodeId": "577",  "fieldName": "width", "fieldValue": 720 },
        { "nodeId": "577",  "fieldName": "height", "fieldValue": 1280 },
        { "nodeId": "577",  "fieldName": "batch_size", "fieldValue": 1 }
      ]
    }'

--------------------------------------------------------------------------------
请求参数
--------------------------------------------------------------------------------

字段          类型    必填  说明
webappId      string   是   RunningHub 应用 ID，决定使用哪个工作流。
                           2066139220363800578 = 清风-国漫角色文生图
                           2066116654223937537 = 清风-国漫角色姿势复刻
                           2066150333931409410 = 清风-国漫角色放大
instanceType  string   否   实例规格: default / plus(推荐) / pro
nodeInfoList  array    否   应用参数列表，不传则使用应用默认值。

nodeInfoList 每项结构:
  nodeId      string  ★  参数所属的节点 ID，由 RH 应用定义
  fieldName   string  ★  参数字段名，如 lora_name / text / width / height
  fieldValue  any     ★  参数值。
                         文本字段 → 传 string
                         数字字段 → 传 number
                         布尔字段 → 传 boolean
                         图片/视频/音频 → 先调 upload-asset 接口获取 RH 内部 fileName，再传 string

--------------------------------------------------------------------------------
三个应用的 nodeInfoList 参数对照表
--------------------------------------------------------------------------------

【清风-国漫角色文生图】webappId = 2066139220363800578
  nodeId  fieldName   类型      说明
  1569    lora_name    string    角色模型文件名（从模型API的 versionResourceName 获取）
  1643    text         string    角色外观描述（从模型API的 desc 获取）
  1644    value        boolean   是否随机动作，默认 false
  1646    text         string    动作提示词
  1496    text         string    背景提示词
  577     width        number    图片宽度（8的倍数），默认 720
  577     height       number    图片高度（8的倍数），默认 1280
  577     batch_size   number    批次大小（一次生成几张），默认 1，上限 16

【清风-国漫角色姿势复刻】webappId = 2066116654223937537
  nodeId  fieldName   类型      说明
  1646    image        string    角色姿势参考图（需先上传获取 fileName）
  1569    lora_name    string    角色模型文件名
  1216    text         string    角色外观描述
  1690    value        boolean   是否需要自定义背景
  1496    text         string    背景提示词（条件显示）
  577     batch_size   number    批次大小，默认 2

【清风-国漫角色放大】webappId = 2066150333931409410
  nodeId  fieldName   类型      说明
  1569    lora_name    string    角色模型文件名
  1643    text         string    角色外观描述
  1646    image        string    待放大的原图（需先上传获取 fileName）
  577     width        number    目标宽度
  577     height       number    目标高度
  577     batch_size   number    批次大小

--------------------------------------------------------------------------------
成功响应
--------------------------------------------------------------------------------

{
  "success": true,
  "data": {
    "taskId": "abc123-def456-ghi789",
    "raw": { /* RH 上游原始响应 */ }
  }
}

字段说明:
  data.taskId  string  ★ 任务 ID，后续轮询和取消都要用这个
  data.raw     object    RH 上游原始响应，调试用

--------------------------------------------------------------------------------
失败响应

================================================================================
  五、RunningHub 任务查询（轮询）
================================================================================

接口: GET /api/proxy/runninghub/query

用途: 轮询任务执行状态，获取生成的图片。

curl 示例:
  curl -X GET "http://127.0.0.1:18766/api/proxy/runninghub/query?taskId=abc123-def456-ghi789"

--------------------------------------------------------------------------------
请求参数
--------------------------------------------------------------------------------

参数    类型    必填  说明
taskId  string   是   提交任务时返回的 taskId（Query String 方式传参）

--------------------------------------------------------------------------------
响应（运行中）
--------------------------------------------------------------------------------

{
  "success": true,
  "data": {
    "status": "RUNNING",
    "urls": [],
    "failReason": null,
    "code": 804,
    "raw": { /* RH 上游原始响应 */ }
  }
}

--------------------------------------------------------------------------------
响应（成功完成）
--------------------------------------------------------------------------------

{
  "success": true,
  "data": {
    "status": "SUCCESS",
    "urls": [
      "/files/output/rh_1712345678_a1b2.png",
      "/files/output/rh_1712345678_c3d4.png"
    ],
    "failReason": null,
    "code": 0,
    "raw": { /* RH 上游原始响应 */ }
  }
}

--------------------------------------------------------------------------------
响应（失败）
--------------------------------------------------------------------------------

{
  "success": true,
  "data": {
    "status": "FAILED",
    "urls": [],
    "failReason": "CUDA out of memory...",
    "code": 805,
    "raw": { /* RH 上游原始响应 */ }
  }
}

--------------------------------------------------------------------------------
字段说明
--------------------------------------------------------------------------------

字段            类型          说明
data.status     string        任务状态:
                                PENDING  - 待处理
                                QUEUED   - 排队中 (code=813)
                                RUNNING  - 运行中 (code=804)
                                SUCCESS  - 已完成 (code=0)
                                FAILED   - 失败   (code=805)
data.code       number        RH 上游状态码，对应关系见上方
data.urls       string[]      ★ 产物图片的本地 URL。格式如 /files/output/xxx.png。
                              成功时返回（后端已自动下载转存）。
                              前端拼接成完整 URL: http://127.0.0.1:18766/files/output/xxx.png
data.failReason string|null   失败原因，成功时为 null

--------------------------------------------------------------------------------
轮询建议
--------------------------------------------------------------------------------

- 建议间隔: 5 秒
- 最长等待: 480 次 (40 分钟)，超时后自动停止
- 建议在 UI 中展示进度条或加载动画

================================================================================
  七、素材上传（RunningHub）
================================================================================

接口: POST /api/proxy/runninghub/upload-asset

用途: 将本地图片/视频/音频上传到 RunningHub，获取 RH 内部 fileName，
      用于 submit 接口中 image/video/audio 类型的 nodeInfoList 条目。

curl 示例:
  curl -X POST http://127.0.0.1:18766/api/proxy/runninghub/upload-asset \
    -H "Content-Type: application/json" \
    -d '{"url": "/files/output/my_image.png"}'

--------------------------------------------------------------------------------
请求参数 (JSON Body，limit 20MB)
--------------------------------------------------------------------------------

字段  类型    必填  说明
url   string   是   素材 URL，支持以下格式:
                       - 本地文件: /files/output/xxx.png 或 /files/input/xxx.mp4
                       - 远程 URL: https://... (后端会下载后上传到 RH)

--------------------------------------------------------------------------------
成功响应
--------------------------------------------------------------------------------

{
  "success": true,
  "data": {
    "fileName": "rh_upload_1712345678_a1b2.png",
    "fileType": "image"
  }
}

字段说明:
  data.fileName  string  RH 内部文件名 ★ 提交任务时填到 fieldValue
  data.fileType  string  文件类型: image / video / audio

curl 示例:

--------------------------------------------------------------------------------
请求参数
--------------------------------------------------------------------------------

参数      类型    必填  说明

--------------------------------------------------------------------------------

{

================================================================================
  完整调用流程
================================================================================

  1. 获取模型列表
     GET /api/guoman-models?page=1&size=30&search=小舞
     → 拿到模型 ID、版本文件名、角色外观描述、缩略图等

  2. (可选) 获取应用参数模板
     GET /api/proxy/runninghub/app-info?webappId=2066139220363800578
     → 拿到参数定义，动态渲染表单

  3. (可选) 上传参考图/姿势图
     POST /api/proxy/runninghub/upload-asset
     → 把图片转成 RH 内部 fileName

  4. 提交生成任务
     POST /api/proxy/runninghub/submit
     → 拿到 taskId

  5. 轮询任务状态
     GET /api/proxy/runninghub/query?taskId=xxx
     → 每 5 秒一次，直到 status=SUCCESS 或 FAILED
     → 成功时 urls 数组包含可访问的本地图片 URL

  6. (用户取消时) 取消任务
     POST /api/proxy/runninghub/cancel
     → 终止远程 RH 任务


================================================================================
  关键字段映射关系
================================================================================

  模型列表 API                        Submit API
  ────────────────────────────────────────────────────
  records[i].versions[0]
    .versionResourceName    ──→  nodeInfoList 中 nodeId="1569" fieldName="lora_name" 的 fieldValue
  records[i].desc           ──→  nodeInfoList 中 nodeId="1643" fieldName="text" 的 fieldValue
  records[i].thumbnailUrl   ──→  UI 预览图（不传 Submit）
  records[i].id             ──→  收藏 ID，用于 /by-ids 接口


  图片访问:
  Submit → 拿到 taskId → Query 返回 urls: ["/files/output/xxx.png"]
  → 前端拼接: http://127.0.0.1:18766/files/output/xxx.png
